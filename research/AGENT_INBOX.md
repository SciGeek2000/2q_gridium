## Important

Everything in this file is **UNREVIEWED** until explicitly evaluated by Emiliano and the ChatGPT research-brain workflow.

Agent findings must NOT automatically:

- become accepted scientific conclusions,
- modify the Gridium theoretical formulation,
- generate implementation instructions,
- change simulation parameters,
- override previous project decisions,
- or be treated as established project knowledge.

The workflow is:

Agent finding → UNREVIEWED evidence → ChatGPT + Emiliano review → decision → Codex task if needed.
